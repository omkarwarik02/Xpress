# 🚀 Xpress App

Xpress App is a real-time social media–style web application that allows users to create posts, upload images, and interact through likes with instant updates. The application focuses on performance, security, and real-time user experience.

---

## 📌 Features

- User authentication using JWT
- Create posts with image upload
- Server-side image optimization
- Real-time likes update using Socket.IO
- Live like count without page refresh
- Secure API calls using Angular HTTP Interceptor
- Responsive and interactive UI
- Scalable and modular architecture

---

## 🛠️ Tech Stack

### Frontend
- Angular
- TypeScript
- HTML
- CSS
- PrimeNG

### Backend
- Node.js
- Express.js
- Socket.IO
- JWT Authentication

### Database
- MongoDB

---

## 🔐 Authentication & Security

- JWT-based authentication for secure login
- Tokens are attached automatically using Angular HTTP Interceptor
- Protected routes accessible only to authenticated users

---

## ⚡ Real-Time Features

- Socket.IO enables instant like updates
- All users receive real-time changes without refreshing the page
